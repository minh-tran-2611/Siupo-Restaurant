## Design Context

### Users
Restaurant administrators use the dashboard during daily operations to review customer feedback, identify low ratings, inspect order and product context, and moderate inappropriate content quickly.

### Brand Personality
Professional, clear, and cohesive with the existing Siupo Restaurant admin experience.

### Aesthetic Direction
Use the existing light Material UI dashboard language, typography, palette, controls, and page composition. The review management page should feel native to the current product rather than introduce a separate visual concept.

### Design Principles
- Reuse established admin components and interaction patterns before adding new ones.
- Keep review status, rating, customer, product, and order context easy to scan.
- Use progressive disclosure: concise table rows with a focused detail dialog for full content and images.
- Make moderation actions explicit, reversible where possible, and accompanied by clear feedback.
- Preserve responsive behavior, keyboard focus, loading, empty, and error states.
